TẠO WEB TAGOCO V3

1. Mở file index.html để xem thử trên máy tính.
2. Đưa toàn bộ nội dung thư mục này lên GitHub hoặc Cloudflare Pages.
3. Có sẵn:
   - Giao diện responsive cho máy tính và điện thoại.
   - 9 sản phẩm.
   - Tạo tài khoản và đăng nhập lưu bằng localStorage.
   - Giỏ hàng, tăng giảm số lượng, nút Đặt mua hàng.
   - Form nhận hàng, tự sinh mã đơn TGYYMMDDxxx.
   - Tra cứu đơn hàng đã tạo trên cùng trình duyệt.

LƯU Ý:
Bản này là website tĩnh nên tài khoản và đơn hàng chỉ được lưu trong trình duyệt của khách.
Để nhận đơn thật từ mọi khách và quản lý trên điện thoại, bước tiếp theo cần kết nối cơ sở dữ liệu miễn phí
như Supabase/Firebase hoặc Cloudflare D1, đồng thời tạo trang quản trị /admin.
